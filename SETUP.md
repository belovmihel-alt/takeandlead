# Инструкция по развертыванию системы бронирования
## Для начинающих (полный нуль в программировании)

Эта инструкция поможет вам запустить систему бронирования экскурсоводов на вашем компьютере. Следуйте каждому шагу по порядку.

---

## Шаг 1: Установка необходимых программ

### 1.1 Установка Node.js

**Что это?** Node.js - это программа, которая позволяет запускать JavaScript код на вашем компьютере (без браузера).

**Как установить:**

1. Откройте браузер и перейдите на сайт: https://nodejs.org/
2. Скачайте версию **LTS** (рекомендуемая) для вашей операционной системы:
   - **Windows**: нажмите на кнопку "Windows Installer"
   - **macOS**: нажмите на кнопку "macOS Installer"
   - **Linux**: следуйте инструкциям для вашего дистрибутива
3. Запустите скачанный файл
4. Следуйте инструкциям установщика (можно оставить все настройки по умолчанию)
5. Нажимайте "Далее" → "Далее" → "Установить" → "Готово"

**Проверка установки:**

1. Откройте **Командную строку** (Windows) или **Терминал** (macOS/Linux):
   - **Windows**: Нажмите `Win + R`, введите `cmd` и нажмите Enter
   - **macOS**: Нажмите `Cmd + Пробел`, введите `terminal` и нажмите Enter
   - **Linux**: Нажмите `Ctrl + Alt + T`

2. Введите команду:
   ```bash
   node --version
   ```
3. Вы должны увидеть что-то вроде: `v20.10.0`
4. Также проверьте npm:
   ```bash
   npm --version
   ```
5. Вы должны увидеть что-то вроде: `10.2.3`

✅ Если видите версии - всё установлено правильно!

---

### 1.2 Установка PostgreSQL (База данных)

**Что это?** PostgreSQL - это программа для хранения данных (пользователи, бронирования, экскурсии и т.д.).

**Как установить:**

#### Windows:

1. Перейдите на сайт: https://www.postgresql.org/download/windows/
2. Нажмите на "Download the installer"
3. Выберите версию **15.x** для Windows x86-64
4. Запустите скачанный файл
5. В процессе установки:
   - Компоненты: оставьте все галочки
   - Директория: можно оставить по умолчанию
   - **ВАЖНО! Пароль**: придумайте и **запомните** пароль (например, `postgres123`)
   - Порт: оставьте `5432`
   - Locale: оставьте по умолчанию
6. Нажмите "Next" до конца установки

#### macOS:

1. Перейдите на сайт: https://postgresapp.com/
2. Нажмите "Download"
3. Откройте скачанный `.dmg` файл
4. Перетащите Postgres.app в папку Applications
5. Запустите Postgres.app
6. Нажмите "Initialize" для создания первого сервера

#### Linux (Ubuntu/Debian):

Откройте терминал и выполните:
```bash
sudo apt update
sudo apt install postgresql postgresql-contrib
```

**Проверка установки:**

1. Откройте командную строку/терминал
2. Введите (Windows):
   ```bash
   psql --version
   ```
   Или (macOS/Linux):
   ```bash
   psql --version
   ```
3. Вы должны увидеть: `psql (PostgreSQL) 15.x`

✅ Если видите версию - всё установлено правильно!

---

### 1.3 Установка Git

**Что это?** Git - программа для работы с кодом (скачивание, сохранение изменений).

**Как установить:**

#### Windows:
1. Перейдите на: https://git-scm.com/download/win
2. Скачайте установщик (64-bit)
3. Запустите установщик
4. Оставьте все настройки по умолчанию, просто нажимайте "Next"
5. Нажмите "Install" → "Finish"

#### macOS:
1. Откройте Терминал
2. Введите:
   ```bash
   git --version
   ```
3. Если Git не установлен, появится окно с предложением установить. Нажмите "Установить"

#### Linux:
```bash
sudo apt install git
```

**Проверка:**
```bash
git --version
```

✅ Должны увидеть версию Git

## Шаг 3: Создание базы данных

### 3.1 Создание БД через командную строку PostgreSQL

#### Windows:

1. Найдите в меню "Пуск" программу **"SQL Shell (psql)"**
2. Запустите её
3. Нажимайте **Enter** на всех вопросах (оставляя значения по умолчанию), кроме последнего
4. Когда попросит пароль - введите пароль, который вы придумали при установке PostgreSQL
5. Вы должны увидеть: `postgres=#`

#### macOS (Postgres.app):

1. Откройте Терминал
2. Введите:
   ```bash
   psql postgres
   ```

#### Linux:

1. Откройте Терминал
2. Введите:
   ```bash
   sudo -u postgres psql
   ```

### 3.2 Создание базы данных

В открытом psql введите команду:

```sql
CREATE DATABASE museum_booking;
```

Вы должны увидеть: `CREATE DATABASE`

Проверьте, что база создана:
```sql
\l
```

В списке должна быть база `museum_booking`

Выйдите из psql:
```sql
\q
```

✅ База данных создана!

## Шаг 4: Настройка проекта

### 4.1 Установка зависимостей

1. Откройте **Visual Studio Code**
2. В меню выберите: **Файл** → **Открыть папку**
3. Найдите и выберите папку `takeandlead`
4. Откройте встроенный терминал в VS Code:
   - Меню: **Вид** → **Терминал**
   - Или нажмите: `Ctrl + ~` (тильда)

5. В терминале введите команду:
   ```bash
   npm install
   ```

   **Это займет 2-5 минут.** Программа скачает все необходимые библиотеки.

6. Подождите, пока не увидите снова приглашение командной строки

✅ Все зависимости установлены!

---

### 4.2 Настройка переменных окружения

Переменные окружения - это настройки для подключения к базе данных и другие важные параметры.

1. В VS Code в левой панели найдите папку `backend`
2. Найдите файл `backend/.env.example`
3. Скопируйте этот файл:
   - Правый клик на файле → **Копировать**
   - Правый клик на папке `backend` → **Вставить**
4. Переименуйте скопированный файл в `.env` (уберите `.example`)

5. Откройте файл `.env` двойным кликом

6. **ВАЖНО!** Измените следующие строки:

   ```env
   DB_PASSWORD=ваш_пароль_от_postgresql
   ```

   Замените `ваш_пароль_от_postgresql` на пароль, который вы придумали при установке PostgreSQL

7. Измените секретные ключи на случайные строки (для безопасности):

   ```env
   JWT_SECRET=придумайте_длинную_случайную_строку_123456789
   QR_SECRET=другая_длинная_случайная_строка_987654321
   ```

8. Сохраните файл: `Ctrl + S` (Windows/Linux) или `Cmd + S` (macOS)

**Пример готового .env файла:**
```env
PORT=5000
NODE_ENV=development

DB_HOST=localhost
DB_PORT=5432
DB_NAME=museum_booking
DB_USER=postgres
DB_PASSWORD=postgres123

JWT_SECRET=my_super_secret_key_12345_abcdef
JWT_EXPIRES_IN=7d

QR_SECRET=my_qr_secret_key_67890_ghijkl

FRONTEND_URL=http://localhost:3000
```

✅ Файл настроек готов!

## Шаг 5: Запуск миграций базы данных

Миграции - это создание таблиц в базе данных.

1. В терминале VS Code перейдите в папку backend:

   ```bash

   ```

3. Вы должны увидеть сообщения о создании таблиц:

## Возможные проблемы и решения

### ❌ Проблема: "npm: command not found"

**Решение:**
- Node.js не установлен или установлен неправильно
- Перезагрузите компьютер после установки Node.js
- Проверьте установку: `node --version`

---

### ❌ Проблема: "psql: command not found"

**Решение:**
- PostgreSQL не добавлен в PATH
- **Windows**: Добавьте `C:\Program Files\PostgreSQL\15\bin` в переменную PATH
- **macOS**: Установите через Homebrew: `brew install postgresql@15`

---

### ❌ Проблема: "password authentication failed"

**Решение:**
- Неправильный пароль в файле `.env`
- Проверьте, что `DB_PASSWORD` в `.env` совпадает с паролем PostgreSQL
- Попробуйте войти в psql вручную с этим паролем

---

### ❌ Проблема: "Port 5000 is already in use"

**Решение:**
- Порт 5000 занят другой программой
- **Вариант 1**: Остановите программу, использующую порт 5000
- **Вариант 2**: Измените порт в `.env`: `PORT=5001`

---

### ❌ Проблема: "Cannot connect to database"

**Решение:**
1. Проверьте, что PostgreSQL запущен:
   - **Windows**: Откройте "Службы" → найдите "postgresql-x64-15" → должна быть "Запущена"
   - **macOS**: Откройте Postgres.app → сервер должен быть зеленым
   - **Linux**: `sudo systemctl status postgresql`

2. Проверьте настройки в `.env`:
   - `DB_HOST=localhost`
   - `DB_PORT=5432`
   - `DB_NAME=museum_booking`
   - `DB_USER=postgres`

---

### ❌ Проблема: Белый экран в браузере

**Решение:**
1. Проверьте консоль браузера (F12 → Console)
2. Убедитесь, что backend запущен (http://localhost:5000/health должен отвечать)
3. Проверьте, что frontend запущен на порту 3000

### Создание администратора

Чтобы создать администратора, нужно изменить роль пользователя в базе данных:

1. Откройте psql:
   ```bash
   psql -U postgres -d museum_booking
   ```

2. Найдите свой email:
   ```sql
   SELECT id, email, role FROM users;
   ```

3. Измените роль на admin:
   ```sql
   UPDATE users SET role = 'admin' WHERE email = 'ваш@email.com';
   ```

4. Выйдите:
   ```sql
   \q
   ```

5. Перезайдите в систему
