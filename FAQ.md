# Часто задаваемые вопросы (FAQ)

## Общие вопросы

### ❓ Что это за система?

Это веб-приложение для управления внештатными экскурсоводами в музее. Система позволяет:
- Экскурсоводам бронировать таймслоты
- Генерировать QR-пропуска для входа в музей
- Отслеживать заработок и статистику
- Администраторам управлять расписанием и выплатами

---

### ❓ Нужен ли интернет для работы?

**Нет**, после установки система работает локально на вашем компьютере без интернета.

Интернет нужен только для:
- Первоначальной установки программ
- Скачивания проекта с GitHub

---

### ❓ Можно ли использовать на телефоне?

**Частично**. Веб-интерфейс адаптивный и откроется на телефоне, но:
- Телефон должен быть в одной сети Wi-Fi с компьютером, где запущен сервер
- Нужно знать IP-адрес вашего компьютера
- Лучше использовать на компьютере или планшете

---

### ❓ Сколько занимает места на диске?

Приблизительно:
- Проект: ~200 МБ
- Node.js: ~100 МБ
- PostgreSQL: ~200 МБ
- **Итого**: около 500 МБ

### ❓ Какую версию PostgreSQL выбрать?

Рекомендуется **PostgreSQL 15** или новее. Версия 14 тоже подойдет.

---

### ❓ Я забыл пароль от PostgreSQL, что делать?

**Решение для Windows:**

1. Найдите файл `pg_hba.conf`:
   - Обычно здесь: `C:\Program Files\PostgreSQL\15\data\pg_hba.conf`
2. Откройте его текстовым редактором (от имени администратора)
3. Найдите строки с `md5` и замените на `trust`:
   ```
   # IPv4 local connections:
   host    all             all             127.0.0.1/32            trust
   ```
4. Сохраните файл
5. Перезапустите службу PostgreSQL:
   - Службы → postgresql-x64-15 → Перезапустить
6. Теперь можете войти без пароля:
   ```bash
   psql -U postgres
   ```
7. Смените пароль:
   ```sql
   ALTER USER postgres PASSWORD 'новый_пароль';
   ```
8. Верните `md5` обратно в `pg_hba.conf`
9. Снова перезапустите службу

## Работа с системой

### ❓ Как создать администратора?

После регистрации обычного пользователя:

1. Откройте psql:
   ```bash
   psql -U postgres -d museum_booking
   ```

2. Измените роль на admin:
   ```sql
   UPDATE users SET role = 'admin' WHERE email = 'ваш@email.com';
   ```

3. Перезайдите в систему

---

### ❓ Как создать таймслот экскурсии?

Только администратор может создавать таймслоты:

1. Войдите как администратор
2. Перейдите в админ-панель (пока заглушка, нужно будет реализовать UI)
3. Используйте API напрямую или через Postman

**Пример через curl:**
```bash
curl -X POST http://localhost:5000/api/slots \
  -H "Authorization: Bearer ВАШ_ТОКЕН" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Экскурсия по залу №1",
    "start_datetime": "2025-02-01T10:00:00Z",
    "end_datetime": "2025-02-01T11:30:00Z",
    "duration_min": 90,
    "language": "ru",
    "hall": "Зал 1",
    "base_fee": 1500
  }'
```

---

### ❓ Как экскурсовод видит свой QR-код?

1. Войдите как экскурсовод
2. Перейдите на страницу "QR-пропуск" (в меню)
3. QR-код сгенерируется автоматически
4. Можно сохранить как картинку или показать с экрана

---

### ❓ Как долго действует QR-код?

**24 часа** с момента генерации. После этого нужно сгенерировать новый.

---

### ❓ Можно ли отменить бронирование?

**Да**, экскурсовод может отменить своё бронирование до начала экскурсии:
1. Перейдите в "Мои бронирования"
2. Нажмите "Отменить" у нужного бронирования

## Технические вопросы

### ❓ Что делать, если порт 5000 занят?

1. Откройте файл `backend/.env`
2. Измените строку:
   ```env
   PORT=5001
   ```
3. Перезапустите приложение
4. Backend теперь на http://localhost:5001

**Важно!** Также измените в `frontend/.env`:
```env
VITE_API_URL=http://localhost:5001/api
```

---

### ❓ База данных сломалась, как восстановить?

**Вариант 1: Пересоздать базу**

```bash
# Войдите в psql
psql -U postgres

# Удалите базу
DROP DATABASE museum_booking;

# Создайте заново
CREATE DATABASE museum_booking;

# Выйдите
\q

# Запустите миграции
cd backend
npm run db:migrate
```

**Вариант 2: Откат миграций**

```bash
cd backend
npm run db:rollback  # откатить последнюю миграцию
npm run db:migrate   # применить заново
```

---

### ❓ Как посмотреть, что в базе данных?

### ❓ Можно ли запустить на нескольких компьютерах?

Это требует знаний по настройке сети.

## Ошибки и их решение

### ❓ Ошибка: "ECONNREFUSED 127.0.0.1:5432"

**Причина:** PostgreSQL не запущен

**Решение:**
1. Запустите PostgreSQL (см. SETUP.md)
2. Проверьте порт в `.env` (должен быть 5432)

---

### ❓ Ошибка: "Migration table is already locked"

**Причина:** Миграция была прервана и база осталась в заблокированном состоянии

**Решение:**
```bash
psql -U postgres -d museum_booking
DELETE FROM knex_migrations_lock;
\q

cd backend
npm run db:migrate
```

---

### ❓ Ошибка: "Cannot find module"

**Причина:** Не установлены зависимости

**Решение:**
```bash
# В корне проекта
npm install

# Если не помогло, удалите node_modules
rm -rf node_modules
rm -rf backend/node_modules
rm -rf frontend/node_modules

# И установите заново
npm install
```

---

### ❓ Ошибка: "Unauthorized" при попытке создать таймслот

**Причина:** Нет прав доступа или неправильный токен

**Решение:**
1. Проверьте, что вы вошли как администратор
2. Проверьте роль в БД:
   ```sql
   SELECT email, role FROM users;
   ```
3. Если роль не admin, измените:
   ```sql
   UPDATE users SET role = 'admin' WHERE email = 'ваш@email.com';
   ```

## Безопасность

### ❓ Безопасно ли использовать в реальном музее?

Текущая версия подходит для **тестирования и разработки**.

Для production нужно:
1. Использовать HTTPS (SSL-сертификаты)
2. Настроить firewall
3. Использовать сложные секретные ключи
4. Настроить регулярные бэкапы БД
5. Включить логирование
6. Настроить мониторинг

---

### ❓ Где хранятся пароли?

Пароли **не хранятся в открытом виде**. В базе хранится хеш (зашифрованная версия) с использованием bcrypt.
