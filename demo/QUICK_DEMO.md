# Быстрый запуск демо для презентации

## За 5 минут до встречи:

### 1. Установите зависимости (ОДИН РАЗ)

```bash
cd demo
npm install
```

### 2. Запустите демо

```bash
npm run dev
```

Приложение откроется на **http://localhost:3001**

### 3. Откройте в браузере

Откройте http://localhost:3001 в Chrome или Safari

**Важно!** Включите режим "Мобильное устройство" (F12 → иконка телефона)

---

3. **Кликнуть на слот**

## Если что-то сломалось:

### Не запускается npm run dev
```bash
rm -rf node_modules
npm install
npm run dev
```

### Ошибка "Port 3001 already in use"
Закройте предыдущий запуск или измените порт в `vite.config.js`
