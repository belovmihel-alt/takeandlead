# Запуск демо на Windows (PowerShell)

## Пошаговая инструкция

### Шаг 1: Откройте PowerShell

**Способ 1:**
- Нажмите `Win + X`
- Выберите "Windows PowerShell" или "Терминал"

**Способ 2:**
- Нажмите `Win + R`
- Введите `powershell`
- Нажмите Enter

**Способ 3:**
- В поиске Windows введите "PowerShell"
- Кликните на "Windows PowerShell"

---

### Шаг 2: Перейдите в папку проекта

Найдите где у вас лежит проект. Например, если проект в `C:\Users\ВашеИмя\Documents\takeandlead`:

```powershell
cd C:\Users\ВашеИмя\Documents\takeandlead\demo
```

**Совет:** Если не помните путь, можно:
1. Открыть папку `takeandlead\demo` в Проводнике
2. В адресной строке вверху написать `powershell` и нажать Enter
3. PowerShell откроется уже в нужной папке!

---

### Шаг 3: Установите зависимости (ОДИН РАЗ)

```powershell
npm install
```

**Что произойдет:**
- Скачаются все необходимые библиотеки
- Это займет 1-3 минуты
- Увидите много текста - это нормально
- Ждите пока не появится снова приглашение командной строки

**Если появится ошибка про права:**
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```
Введите `Y` и нажмите Enter, затем снова `npm install`

---

### Шаг 4: Запустите демо

```powershell
npm run dev
```

**Что увидите:**
```
  VITE v5.0.8  ready in 1234 ms

  ➜  Local:   http://localhost:3001/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

**Не закрывайте это окно PowerShell!** Оно должно оставаться открытым.

---

### Шаг 5: Откройте в браузере

1. Откройте **Google Chrome** или **Microsoft Edge**
2. Перейдите по адресу: **http://localhost:3001**
3. Нажмите `F12` для открытия инструментов разработчика
4. Нажмите на иконку **телефона** (Toggle device toolbar) или `Ctrl + Shift + M`
5. Выберите в списке "iPhone 12 Pro" или любой другой телефон

**Готово!** Демо запущено! 🎉

---

Когда закончите презентацию:

1. Вернитесь в окно PowerShell
2. Нажмите `Ctrl + C`
3. Если спросит "Terminate batch job (Y/N)?" - введите `Y`

## Возможные проблемы и решения

### ❌ "npm : The term 'npm' is not recognized"

**Проблема:** Node.js не установлен или не добавлен в PATH

**Решение:**
1. Скачайте Node.js с https://nodejs.org/
2. Установите (LTS версия)
3. Перезапустите PowerShell
4. Попробуйте снова

---

### ❌ "cannot be loaded because running scripts is disabled"

**Решение:**
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```
Введите `Y` и нажмите Enter

---

### ❌ "Port 3001 is already in use"

**Проблема:** Порт занят другой программой

**Решение 1:** Закройте предыдущий запуск демо (если был)

**Решение 2:** Измените порт в `demo\vite.config.js`:
```javascript
server: {
  port: 3002,  // Измените на другой порт
  host: true
}
```

---

### ❌ Белый экран в браузере

**Решение:**
1. Подождите 10-20 секунд (возможно еще загружается)
2. Обновите страницу (F5)
3. Проверьте консоль (F12 → Console) на наличие ошибок
4. Убедитесь что в PowerShell нет красных ошибок

---

## Альтернативный способ (через Проводник)

Если не хотите использовать PowerShell:

1. Откройте папку `takeandlead\demo` в Проводнике
2. В адресной строке (где путь) удалите текст
3. Введите `powershell` и нажмите Enter
4. PowerShell откроется в этой папке
5. Введите `npm run dev`
