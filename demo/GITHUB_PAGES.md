# Развертывание демо на GitHub Pages

## Автоматическое развертывание (рекомендуется)

### Шаг 1: Включите GitHub Pages в репозитории

1. Откройте ваш репозиторий на GitHub: https://github.com/belovmihel-alt/takeandlead
2. Перейдите в **Settings** (Настройки)
3. В левом меню найдите **Pages**
4. В разделе "Build and deployment":
   - Source: выберите **GitHub Actions**
5. Нажмите **Save**

### Шаг 2: Запушьте изменения

Файл `.github/workflows/deploy-demo.yml` уже создан и настроен.

```bash
cd takeandlead
git add .
git commit -m "Настроена автоматическая публикация демо на GitHub Pages"
git push
```

### Шаг 3: Подождите

1. Перейдите во вкладку **Actions** в вашем репозитории
2. Дождитесь завершения workflow (займет 1-2 минуты)
3. Демо будет доступно по адресу:

**https://belovmihel-alt.github.io/takeandlead/**

---

## Ручное развертывание (альтернатива)

Если не хотите использовать GitHub Actions:

### 1. Соберите проект локально

```bash
cd demo
npm install
npm run build
```

### 2. Установите gh-pages

```bash
npm install -g gh-pages
```

### 3. Опубликуйте

```bash
gh-pages -d dist
```

Демо будет доступно через несколько минут.

## Использование в Telegram Mini App

Когда демо опубликовано на GitHub Pages, можете создать настоящий Telegram Mini App:

### 1. Создайте бота

1. Откройте [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду: `/newbot`
3. Следуйте инструкциям (придумайте имя и username)

### 2. Создайте Mini App

1. В [@BotFather](https://t.me/botfather) отправьте: `/newapp`
2. Выберите вашего бота
3. Введите название: `Музей РТ - Бронирование`
4. Введите описание
5. **Вставьте URL**: `https://belovmihel-alt.github.io/takeandlead/`
6. Загрузите иконку (опционально)

### 3. Готово!

Теперь можете открыть ваше приложение прямо в Telegram!

## Обновление демо

Каждый раз когда вы пушите изменения в папку `demo/`, GitHub автоматически:
1. Соберет новую версию
2. Опубликует на GitHub Pages
3. Обновит сайт

Просто делайте:
```bash
git add demo/
git commit -m "Обновлено демо"
git push
```

## Проверка статуса публикации

1. Перейдите на https://github.com/belovmihel-alt/takeandlead
2. Откройте вкладку **Actions**
3. Увидите статус последнего deploy:
   - 🟢 Зеленая галочка = опубликовано успешно
   - 🟡 Желтый круг = еще публикуется
   - 🔴 Красный крестик = ошибка

## Возможные проблемы

### ❌ 404 Not Found

**Решение:** Убедитесь что в `vite.config.js` правильный `base`:
```javascript
base: '/takeandlead/'
```

### ❌ Белый экран после публикации

**Решение:** Очистите кеш браузера или откройте в режиме инкогнито

### ❌ Workflow не запускается

**Решение:** Проверьте что GitHub Pages включен в Settings → Pages
