# Демо Telegram Mini App - Система бронирования экскурсоводов

Демонстрационная версия приложения для презентации концепции системы бронирования экскурсоводов.

## Что это?

Это упрощенная демо-версия Telegram Mini App, созданная специально для презентации. Приложение показывает основную концепцию и UI/UX, но не подключено к реальному backend.

## Возможности демо

### 📊 Статистика
- Уровень экскурсовода с прогресс-баром
- Общая статистика (всего экскурсий, завершено, предстоящих, рейтинг)
- Заработок
- Достижения и бонусы

### 📅 Слоты
- Календарь с доступными датами
- Список экскурсий с информацией:
  - Дата и время
  - Название экскурсии
  - Зал
  - Количество людей в группе
  - Оплата
  - Язык
- При клике на слот показывается QR-код для входа

### 👤 Профиль
- Информация о пользователе
- Статистика экскурсовода
- Языки и специализации
- Документы

## Запуск демо

### 1. Установка зависимостей

```bash
cd demo
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:3001

### 3. Сборка для production

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## Как протестировать в Telegram

### Локальное тестирование:

1. Запустите dev сервер: `npm run dev`
2. Используйте ngrok для публикации локального сервера:
   ```bash
   ngrok http 3001
   ```
3. Скопируйте HTTPS URL от ngrok
4. Создайте бота через [@BotFather](https://t.me/botfather)
5. Настройте Mini App через [@BotFather](https://t.me/botfather):
   - `/newapp`
   - Выберите вашего бота
   - Введите название приложения
   - Вставьте URL от ngrok
   - Загрузите иконку (опционально)

### Production развертывание:

1. Соберите приложение: `npm run build`
2. Загрузите содержимое `dist/` на хостинг с HTTPS:
   - GitHub Pages
   - Netlify
   - Vercel
   - Или любой другой хостинг
3. Настройте Mini App с URL вашего хостинга

## Технологии

- **React** - UI библиотека
- **Vite** - сборщик
- **QRCode** - генерация QR-кодов
- **Telegram WebApp SDK** - интеграция с Telegram

## Особенности демо

- ⚡ Все данные случайные (генерируются локально)
- 🎨 Адаптивный дизайн под мобильные устройства
- 📱 Интеграция с Telegram theme colors
- 🔄 Нет подключения к backend (данные не сохраняются)
- 🎯 Фокус на демонстрации UI/UX концепции
