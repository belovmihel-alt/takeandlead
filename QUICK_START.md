# Быстрый запуск системы
## (для тех, кто уже всё настроил)

Эта инструкция для ежедневного запуска системы после первоначальной настройки.

---

## Запуск системы

### Шаг 1: Запустите PostgreSQL

**Windows:**
- PostgreSQL обычно запускается автоматически
- Проверить можно в Службах Windows → postgresql-x64-15 должна быть "Запущена"

**macOS:**
- Откройте Postgres.app
- Убедитесь, что сервер запущен (зеленая кнопка)

**Linux:**
```bash
sudo systemctl start postgresql
```

---

### Шаг 2: Откройте проект

1. Откройте **Visual Studio Code**
2. **Файл** → **Открыть папку** → выберите папку `takeandlead`
3. Откройте терминал: **Вид** → **Терминал** (или `Ctrl + ~`)

---

### Шаг 3: Запустите приложение

В терминале введите:

```bash
npm run dev
```

Подождите 10-20 секунд, пока запустятся backend и frontend.

---

### Шаг 4: Откройте в браузере

Перейдите по адресу: **http://localhost:3000**

✅ **Готово! Система работает!**

---

## Остановка системы

В терминале нажмите: `Ctrl + C`

---

## Что делать, если что-то не работает

### Проблема: "Cannot connect to database"

**Решение:**
1. Убедитесь, что PostgreSQL запущен
2. Проверьте файл `backend/.env` - правильный ли пароль в `DB_PASSWORD`

---

### Проблема: "Port already in use"

**Решение:**
1. Остановите предыдущий запуск (Ctrl + C)
2. Или перезагрузите компьютер

---

### Проблема: Белый экран в браузере

**Решение:**
1. Подождите 20-30 секунд - возможно система еще запускается
2. Обновите страницу в браузере (F5)
3. Проверьте, что в терминале нет ошибок красного цвета

---

### Проблема: Забыли пароль от PostgreSQL

**Решение:**
См. полную инструкцию в **SETUP.md** → раздел "Возможные проблемы"

## Полезные команды

### Просмотр всех пользователей в БД
```bash
psql -U postgres -d museum_booking
SELECT id, email, role FROM users;
\q
```

### Сделать пользователя администратором
```bash
psql -U postgres -d museum_booking
UPDATE users SET role = 'admin' WHERE email = 'email@example.com';
\q
```

### Очистить базу данных
```bash
cd backend
npm run db:rollback
npm run db:migrate
```
